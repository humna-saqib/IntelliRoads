## SUS Scoring Formula

The SUS score is calculated from the 10 Likert responses using the method from Brooke (1996):

1. For **odd-numbered** statements (1, 3, 5, 7, 9) — the contribution is **(response − 1)**.
2. For **even-numbered** statements (2, 4, 6, 8, 10) — the contribution is **(5 − response)**.
3. Sum all 10 contributions.
4. Multiply the sum by **2.5**.

```
SUS score = 2.5 × [ (Q1−1) + (5−Q2) + (Q3−1) + (5−Q4) + (Q5−1)
                   + (5−Q6) + (Q7−1) + (5−Q8) + (Q9−1) + (5−Q10) ]
```

**Score ranges** (Bangor et al., 2008):

| Score | Grade | Adjective |
|---|---|---|
| ≥ 85 | A | Excellent |
| 71 – 84 | B | Good |
| 51 – 70 | C | OK |
| 25 – 50 | D | Poor |
| < 25 | F | Awful |

Average the five individual SUS scores to obtain the **overall SUS score** for the study.
